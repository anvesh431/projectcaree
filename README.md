# CareFlow – Clinical Pathway Process Mining

## Project Overview

CareFlow is a clinical pathway process mining project designed
to analyze hospital patient event logs and identify process
bottlenecks in patient journeys.

## Objective

The objective of this project is to discover the actual patient
journey through hospital activities, analyze transition times,
identify bottlenecks, and visualize the process using Power BI.

## Technology Stack

- Python
- BigQuery
- dbt
- PM4Py
- Power BI

## Main Modules

1. EHR Event Log Simulation
2. Data Cleaning and Normalization
3. BigQuery Data Warehouse
4. dbt Transformation
5. Process Discovery using PM4Py
6. Bottleneck Analysis
7. Power BI Dashboard
8. Conformance Checking

## Project Workflow

Raw Event Logs
       ↓
Data Cleaning
       ↓
BigQuery
       ↓
dbt Transformation
       ↓
PM4Py Process Mining
       ↓
Bottleneck Analysis
       ↓
